# SentimentScope 使用指南

SentimentScope 将数据采集、证据检索、多 Agent 研判、讨论和报告串成完整流程。研究工作台负责分析与报告，采集控制台负责获取社交内容和公开网页证据，两个模块共用舆情数据库。

## 启动与入口

在项目根目录执行：

```powershell
.\Start.ps1
```

- 研究工作台：<http://127.0.0.1:3000>
- 采集控制台：<http://127.0.0.1:5173>
- 研究 API：<http://127.0.0.1:5001/docs>
- 采集 API：<http://127.0.0.1:9000/docs>

停止应用执行 `.\Stop.ps1`。数据库已经运行时，可用 `.\Start.ps1 -SkipDatabase`。停止应用保留数据库、任务、报告和登录状态。停止前可在研究页取消运行中的研究；意外中断的任务会在下次启动标记为中断。

## 快速体验

1. 打开研究工作台，选择“模拟演示”，填写“示例品牌配送调整”并开始分析。该模式使用固定合成证据，不调用模型。
2. 查看 Insight 和 Media 的研究结果，进入“主持人”查看讨论与五维配对研判。
3. 打开“查看证据与基础评测”，展开证据并核对来源。
4. 进入“报告”，选择已完成任务，生成、预览或下载 HTML / Markdown。
5. 在历史任务中查看结果或重新研究；进行中的研究可取消。

研究历史支持按主题搜索与状态筛选；完整角色产物可展开查看。切换任务后，证据与评测需要重新读取，避免沿用上一任务的展示内容。采集概览中的统计来自实际接口，加载失败时显示不可用提示，可在连接恢复后刷新。

## 使用真实数据

1. 在研究工作台的“配置”中填写模型与搜索服务设置，保存后检查连通性。
2. 在采集控制台创建关键词采集任务。首次使用或登录过期时，在弹出的浏览器完成登录，保持浏览器打开直到任务结束。
3. 查看控制台的阶段、内容数、评论数与入库结果。后台接口采集时，浏览器页面不一定持续变化。
4. 如需新闻、公告等网页证据，在“网页证据”中填写研究主题和公开网址。关联话题须与后续研究主题完全相同。
5. 回到研究工作台，选择真实分析并输入主题，等待 Insight、Media、Host 完成研究，再查看证据、讨论和报告。

具体平台支持、登录、超时和重试规则见 [采集指南](crawler.md)。微博已通过真实采集验证；其他社交平台仍需完成登录后验证。需要登录、验证码或脚本渲染的网页暂不支持正文提取。

## 模块职责

| 模块 | 功能 |
| --- | --- |
| 采集控制台 | 关键词任务、网页证据、实时进度、历史与重试 |
| Insight Agent | 检索本地舆情内容，归纳私域证据 |
| Media Agent | 检索公开信息和本地网页证据，归纳公域观点 |
| Host Agent | 组织讨论、五维配对研判并形成综合结论 |
| 报告与评测 | 汇编角色报告、导出产物、检查引用和维度覆盖 |

真实分析与模拟演示分别标记。证据、事件和角色报告按 `research_id` 隔离，同主题不同轮次不会混用报告。报告汇编组合三个角色的产物，不额外调用模型裁判。

基础评测检查引用编号存在性、五维覆盖与耗时。模拟样例的引用有效性不能用于衡量真实模型质量。RAGAS 评测需提供评判模型、embedding 服务和人工参考答案，目前尚未产生真实评分，配置见 [评测说明](../../apps/research-api/evaluation/README.md)。

## 配置与数据

| 路径 | 用途 |
| --- | --- |
| `config/research.env` | 模型、搜索与研究设置 |
| `config/crawler.env` | 采集与话题分析设置 |
| `config/database.env` | 本机数据库连接 |
| `var/research/` | 任务、证据、讨论和报告 |
| `var/crawler/` | 采集任务、批次输出与诊断日志 |
| `var/browser/` | 浏览器登录状态 |
| `var/runtime/` | 应用日志与检查结果 |

数据库在本机 13326 端口运行，初始化 SQL 仅在首次创建数据库卷时导入。后续启动不会覆盖已有记录。默认检索使用 MySQL 多通道检索和规则聚类，Milvus 与语义模型聚类默认关闭。

当前支持本机单实例运行，采集任务串行执行；用户鉴权、分布式队列与多实例恢复尚未实现。

安装、依赖与检查命令见 [开发指南](../development.md)，模块关系见 [架构说明](../architecture.md)。
